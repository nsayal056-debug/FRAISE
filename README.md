# 🍰 FRAISE Pastelería

Aplicación web desarrollada como proyecto de formación en Desarrollo Web.

FRAISE es una tienda online de pastelería que permite explorar diferentes categorías de productos, consultar información detallada y utilizar un carrito de compras.

## 🌐 Demo

👉 https://nsayal056-debug.github.io/FRAISE/

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- MockAPI

## ✨ Funcionalidades

- Navegación dinámica tipo SPA
- Catálogo de productos
- Categorías de tortas, cheesecakes y tartas
- Vista detallada de productos
- Carrito de compras
- Formularios con validaciones
- Integración con MockAPI
- Diseño responsive
- Navegación entre vistas sin recargar completamente la página

## 📂 Estructura del proyecto

- `index.html` — punto de entrada de la aplicación
- `css/` — estilos de la aplicación
- `js/` — lógica y funcionalidades
- `views/` — diferentes vistas de la SPA
- `img/` — imágenes y recursos gráficos

## 🎯 Objetivo del proyecto

El objetivo de FRAISE fue aplicar de manera práctica los conocimientos adquiridos durante mi formación en Desarrollo Web, trabajando con HTML, CSS y JavaScript y desarrollando una aplicación web funcional.

También implementé conceptos como manipulación del DOM, navegación dinámica, consumo de API y manejo de datos.
